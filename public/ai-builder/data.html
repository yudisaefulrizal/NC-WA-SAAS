Panduan API koleksi

Server NC-WA mengirim POST JSON {action, collection, query, context}. context berisi account_id, data_profile_id, session_id, customer, dan request_id; collection berisi id, nama, milik_pelanggan, dan daftar field. Token dikirim sebagai Bearer token, setiap permintaan membawa header Idempotency-Key. Respons wajib HTTP 200 JSON.

search: query {keyword, filters:[{match, conditions:[{field, operator, value}]}], sort, limit}, balas {"records":[{"id":"…","data":{…}}],"has_more":false}. get: query {id}, balas {"records":[…]} (kosong bila tidak ada). count: seperti search ditambah sum_field, balas {"count":0,"total":0}. create: query {data}; update: query {id, data} berisi field yang diubah (null berarti dikosongkan); keduanya membalas record {"id":"…","data":{…}}. delete: query {id}.

Isi data harus sesuai tipe field koleksi. Koleksi milik pelanggan wajib dibatasi ke context.customer. Endpoint HTTPS publik tanpa redirect; batas respons 64 KB dan timeout 15 detik. Mengganti URL tanpa token baru menghapus token lama.
