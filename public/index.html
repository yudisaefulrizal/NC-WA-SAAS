Data profil Anda

Isi bisnis yang dibaca profil AI. Satu data profil bisa dipasang ke beberapa sesi dan tetap tersimpan saat dicabut.

Pilih nomor layanan di atas terlebih dahulu untuk mengatur knowledge, sumber data, perilaku, dan fallback.

Biaya dan syarat ditulis per program di Program, tanggal di Jadwal, nomor per bagian di Kontak.

Program

Belum ada program. Tambahkan program, lalu tulis deskripsinya.

Jadwal

Tanggal pendaftaran, gelombang, tes, kunjungan, event, kalender akademik, libur, dan pengumuman. Tempel apa adanya; AI membaca tanggal hari ini sehingga tahu mana yang sudah lewat.

Dokumen

Tulis deskripsi lalu unggah file. AI membaca deskripsi untuk tahu kapan file dikirim. PDF, Word, Excel, PowerPoint (maks. 10 MB) atau gambar JPG, PNG, WebP (maks. 5 MB).

Setiap dokumen dikirim paling banyak sekali per percakapan dan memakai 1 kredit WhatsApp. Gambar tampil sebagai foto di WhatsApp, file lain sebagai dokumen. Jangan unggah dokumen berisi data pribadi siswa atau wali.

Kontak

AI memberikan kontak bagian yang sesuai dengan keperluan penanya, berdasarkan deskripsinya. Isi dengan kontak resmi lembaga.

Kontak boleh berupa nomor WhatsApp, telepon, atau email. Berbeda dengan Fallback Tim di Knowledge: Fallback Tim memberi tahu tim saat AI tidak bisa menjawab, sedangkan Kontak diberikan langsung kepada penanya.

Pengaturan sumber data produk

Panduan custom endpoint produk

Endpoint menerima POST JSON dengan action, query, dan context (account_id, data_profile_id, session_id, customer, request_id; session_id bernilai null saat diuji dari halaman Data Profil). Token opsional dikirim sebagai Bearer token. Respons wajib HTTP 200 JSON.

Action get_products, query berisi nama atau string kosong. Respons {"products":[{"name":"Produk A","type":"product","description":"Produk harian, satuan pcs","price":125000,"stock":10,"active":true}]}. Maksimal 20 produk; harga dalam rupiah; nama wajib unik per data profil.

Endpoint wajib membatasi data menurut context dan token. Endpoint HTTPS publik, tanpa redirect; batas respons 32 KB dan timeout 15 detik. Mengganti URL tanpa token baru menghapus token lama.

          Autentikasi & mulai cepat
          Buat API key di menu Integrasi. Kirim melalui header X-API-Key pada setiap request. Satu Base URL dipakai semua akun; key menentukan kepemilikan sesi dan data. Gunakan Content-Type: application/json untuk body JSON. Simpan key pada backend aplikasi Anda.
          Base URL: . Endpoint gateway tidak memakai awalan /api, kecuali pemeriksaan identitas /api/client/me. Pengaturan dashboard dan pembelian menggunakan login browser, bukan API key.
          export BASE_URL="BASE_URL_APLIKASI"
export API_KEY="KEY_ANDA"

curl "$BASE_URL/api/client/me" -H "X-API-Key: $API_KEY"
curl "$BASE_URL/sessions" -H "X-API-Key: $API_KEY"

          Webhook, media masuk & realtime
          Daftarkan URL publik melalui POST /webhooks. Tanpa sessionId, webhook menerima event seluruh sesi milik akun. Maksimal 20 langganan per akun. Payload dikirim sebagai JSON melalui HTTP POST; penerima harus merespons sukses (2xx).
          {"event":"message","sessionId":"toko","messageId":"ID_PESAN","from":"628123456789","sender":"628123456789","isGroup":false,"groupId":null,"type":"text","text":"Halo","timestamp":1700000000,"media":null}
          Contoh di atas adalah event pesan teks; field media terisi jika media berhasil disimpan. Event koneksi memakai session.status dan session.qr. Unduh file melalui GET /media/:id dengan API key yang sama.

          Di template tulis {{jumlah}}, {{sisa_kuota}}, dan {{gelombang}}. Contoh hasil: "Promo Gelombang 2 sudah diambil 247 pelanggan. Sisa kuota 53."
          Aturan respons. Respons wajib objek datar: bukan array, tanpa objek bersarang. Bila ada key data berisi objek, isinya yang dibaca; bila tidak, objek akar yang dipakai. Nama variabel hanya huruf, angka, dan garis bawah, maksimal 40 karakter, maksimal 50 variabel. Nilai berupa teks, angka, atau true/false; null, array, dan objek ditolak; maksimal 1000 karakter. Angka diformat gaya Indonesia (1247 menjadi 1.247), true/false menjadi Ya/Tidak. Batas respons 32 KB, timeout 10 detik, wajib HTTPS publik tanpa redirect.
          Media dari endpoint. Tidak ada format khusus: sertakan alamat file sebagai variabel biasa, misalnya {"poster":"https://…/poster.jpg"}, lalu pilih variabel itu pada dialog template. Media wajib HTTPS publik, maksimal 8 MB, dan jenisnya harus cocok dengan jenis konten template. Media diunduh sekali per pengiriman lalu dihapus setelah selesai, sehingga tidak memotong kuota penyimpanan asset.
          Bila data tidak lengkap. Jika satu variabel yang dipakai template tidak ada dalam respons, seluruh pengiriman dibatalkan dan dicatat di Riwayat beserta alasannya. Ini disengaja agar tidak ada pesan setengah jadi terkirim ke kontak. Jadwal berikutnya tetap berjalan seperti biasa.
          Autentikasi. Tambahkan header sesuai kebutuhan endpoint Anda, misalnya X-API-Key: KUNCI_ANDA atau Authorization: Bearer TOKEN. Nama header bebas selama bukan header yang diatur otomatis (Host, Content-Length, Connection, Accept-Encoding). Maksimal 10 header, nilai maksimal 1024 karakter. Nilai disimpan terenkripsi dan tidak pernah ditampilkan kembali; mengganti URL endpoint akan melepas header tersimpan agar rahasia tidak terkirim ke host yang berbeda.
          Gunakan tombol Tes koneksi pada dialog template untuk melihat variabel yang benar-benar dikembalikan endpoint, lalu klik namanya untuk menyisipkannya ke teks.
          Idempotensi, kredit & penanganan error
          Kirim Idempotency-Key yang tetap untuk satu operasi bisnis (1–128 huruf, angka, underscore, atau tanda hubung). Retry dengan payload sama tidak mengirim ulang pesan yang sudah tercatat. Payload berbeda dengan key sama ditolak. Satu teks atau media beserta caption memakai satu kredit; gagal pasti melepas reservasi. Hasil tidak pasti menahan reservasi: jangan membuat key baru untuk langsung mengirim ulang.
          HTTPPenanganan
          400Periksa body, nomor, URL, dan Idempotency-Key.
          401 / 403Periksa kredensial dan hak akses akun.
          404Pastikan ID milik akun dan resource masih tersedia.
          409Periksa error: insufficient_credits, session_limit, idempotency_conflict, atau request_*.
          429 / 503Batas koneksi atau antrean tercapai; beri jeda sebelum mencoba lagi.
          502Bedakan send_failed dan send_unknown; jangan otomatis kirim ulang hasil tidak pasti.
          {"error":"insufficient_credits","message":"Kredit habis."}
          Field message dapat tidak tersedia. Gunakan error untuk penanganan programatik. Maksimal 32 permintaan pengiriman aktif per akun.
